# Calico · 咔嚓猫

一只会算账的小猫。拍一张饭菜照片，它认出食材、估算热量，然后对你的这一顿毫不客气地点评。

微信小程序，原生开发 + 微信云开发，无第三方框架、无构建步骤。

> 状态：开发中（2026.10 起）

---

## 现在能做什么

- **食物搜索**：关键词模糊匹配（名称 / 分类），分类标签筛选，300ms 防抖避免每输入一个字就请求
- **首页**：从云数据库读取食物列表，带加载中 / 失败 / 空数据三种状态
- **食物库**：60 条常见中式食物，含别名（白米饭、地瓜、奇异果）与每 100g 三大营养素

## 规划中

| 模块 | 说明 |
|---|---|
| 记录页 | 选食物 → 填克数 → 存当天记录，热量按快照保存 |
| 猫的点评 | 场景 × 情绪 × 权重的本地台词库，按 7 天去重 |
| 历史趋势 | 近 7 天柱状图，纯 CSS 实现 |
| 拍照识别（V2） | 拍菜品 → 返回菜名 → 可手动纠正 |

## 技术栈

- 原生小程序（WXML / WXSS / JS）
- 微信云开发：云数据库、云函数
- 无 UI 框架、无 echarts（图表用 CSS 画，控制包体）

## 本地运行

1. 微信开发者工具导入本目录
2. 在 `project.config.json` 填入自己的 AppID
3. 开通云开发，创建环境（本项目环境名 `prod`）
4. 云数据库新建集合 `foods`，权限设为「所有用户可读」
5. 导入 `seed/foods.seed.json`（JSON Lines，每行一条），或使用首页的开发期导入按钮

> `data/foods.js` 仅供开发期一次性写入使用，正式环境可删除。

## 几个设计取舍

- **记录存热量快照**：只存 foodId 的话，食物库热量一改，用户三个月前的记录就全变了
- **日期用 `YYYY-MM-DD` 字符串**：按天查询是最高频操作，字符串等值匹配能直接走索引，也绕开时区问题
- **猫的对话不接大模型**：AI 问答属「深度合成」类目，个人主体申请不到；改用规则台词库，输出可枚举、可测试、零调用成本
- **图表不用 echarts**：小程序主包 2MB，echarts 压缩后仍占 500KB+，7 根柱子用 CSS 就够

## 说明

食物热量与营养素为公开成分表的常见参考值，仅作估算参考，不构成医学建议。
